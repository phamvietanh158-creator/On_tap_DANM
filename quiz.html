🗺️ Trụ Địa Chất Khảo Sát 4 Lớp Đất
📖 Bảng tra phân loại đất (TCVN)
1. Đất Dính (A = wL - wP; B = (w-wP)/A):
• A > 17% → Sét
• 7% ≤ A ≤ 17% → Sét pha
• A < 7% → Cát pha
• B > 0.5 → Dẻo chảy ❌
• 0.25 < B ≤ 0.5 → Dẻo mềm ❌
• 0 < B ≤ 0.25 → Nửa cứng ✅
• B ≤ 0 → Cứng / Rất cứng ✅

2. Đất Rời (NSPT hoặc qc):
• NSPT < 10 (qc < 4 MPa) → Rất rời / Rời ❌
• 10 ≤ NSPT < 30 (4 ≤ qc < 12) → Chặt vừa ✅
• NSPT ≥ 30 (qc ≥ 12 MPa) → Chặt / Rất chặt ✅

3. Bùn đất yếu: NSPT < 2 hoặc qc < 0.5 MPa → Chảy ❌
Bước 1: Xác Định Tên Đất & Trạng Thái
Trọng số: 30đ
