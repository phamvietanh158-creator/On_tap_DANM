# Ôn tập và kiểm tra Đồ án Nền móng

Trang cho sinh viên (HTML + CSS + JS thuần, chạy trên điện thoại): móng nông (CLO2), móng cọc (CLO3), ngân hàng câu hỏi chọn đáp án (CLO1–3), đọc hiểu bản vẽ móng (CLO4).

Mỗi lần làm, hệ thống đề xuất một phương án khác; sinh viên tự tính, điền đáp số và trả lời câu tình huống. Chấm điểm ở máy chủ (Cloudflare Worker → Google Apps Script → Google Sheet); trang này không chứa đáp án.
